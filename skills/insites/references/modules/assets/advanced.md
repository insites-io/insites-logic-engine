# Assets: Advanced

Hooks, partials other modules render, and the CRM surfaces this module depends on. Paths are relative to `modules/insites_assets/` in module-v6-assets v6.1.0, read on 9 October 2026.

## Hooks

The module implements one hook, and it is the only file under `public/`:

```
modules/insites_assets/lib/hooks/hook_module_info
```

`public/views/partials/lib/hooks/hook_module_info.liquid` returns `{ name: "Insites Assets", machine_name: "insites_assets", type: "module", version: "6.1.0", updated_at, slug: "assets", label: "Assets" }`. It calls `modules/insites_crm/hook/get_implementations` for `updated_at`. Use it to ask "is Assets installed"; the version string equals the git tag at v6.1.0.

## Partials the admin shell renders

Three private partials exist for the CRM admin shell to include; they are not an override point for your app:

| Partial | Purpose |
|---|---|
| `private/views/partials/insites_menu/insites_assets_side_menu.liquid` | Four `<ins-sidebar-item>` entries |
| `private/views/partials/insites_admin/insites_assets_dependencies.liquid` | Preload + stylesheet for the built bundle |
| `private/views/partials/insites_admin/insites_assets_index_dependencies.liquid` | The `#insites-assets` mount and script tag |

The two `insites_admin` partials are generated by `vue/scripts/write-dependency-partials.mjs` on build and carry the hashed file names; hand edits are lost on the next build.

The module ships no public layouts and no email templates.

## Background work

`functions/reconcile_asset_sizes/` fills `metadata.file_size` for assets that lack it. `maybe_enqueue.liquid` guards (any missing, and no job `SCHEDULED` or `RUNNING` under `source_name` `insites_assets_reconcile_file_sizes`), `enqueue.liquid` starts the `{% background %}` job, and `run_body.liquid` HEAD-requests each asset `url` for 240 seconds or 500 assets, then re-enqueues itself if any remain. Triggers: a successful admin upload (`controllers/files/add.liquid`) and the Reports page load (`controllers/reports/check_file_sizes.liquid`). API creates do not trigger it.

## Reports

`controllers/reports/get_asset_summary.liquid` computes every bucket in Liquid over all assets, 500 per page. `controllers/reports/get_reports.liquid` calls an external metrics service through `private/api_calls/aws/get_reports.liquid` with a short-lived JWT; source does not give that service's response contract beyond `year`, `result`, `created_at`.

## Override points

None in the module. There is no settings record, no override hook and no public partial other than `hook_module_info`. Behaviour you want to change lives in CRM (upload restrictions, policies, response handler) or in the admin SPA.
