# Locator: Advanced

Hooks, partials other modules render, cross-module dependencies and what is not extensible. Facts from module-v6-locator v6.0.2 and the sibling v6 module trees, read 9 October 2026. Paths are relative to `pos/modules/insites_locator/` unless a module name is given.

---

## Module detection: `hook_module_info`

`public/views/partials/lib/hooks/hook_module_info.liquid` is the module's only public partial. It returns `{ name, machine_name: "insites_locator", type: "module", version: "6.0.0", updated_at, slug: "locator", label: "Locator" }` after calling `modules/insites_crm/hook/get_implementations`. Other modules test `context.modules.insites_locator` rather than this hook. The `version` lags the git tag; see [`gotchas.md`](gotchas.md#12-three-version-strings-none-of-them-the-tag) and [`../crm/advanced.md`](../crm/advanced.md#module-detection--hook_module_info).

### SEO partial for public pages

`private/views/partials/seo.liquid` dispatches on a `type` argument to `location_seo.liquid` or `category_seo.liquid`. Each reads `context.params.slug2`, fetches the record by slug (`graphql/{locations,categories}/metadata/get_metadata`) and prints `<title>`, meta description, canonical link and Open Graph tags through `meta_renderer.liquid`. A public page whose route exposes the slug as `slug2` can include `modules/insites_locator/seo` with `type: "location"` or `type: "category"`. No other public-facing partial or layout ships with the module. The partials under `functions/` and `schema/` serve the admin lists, declare no `path:` and carry no contract.

## What is intentionally not extensible

- **No webhooks, notifications, email layouts or public pages.** The only public file is the hook partial; the module implements `hook_module_info` and declares no hooks of its own.
- **No API for custom-field definition create or update, FAQs, attachments, imports, exports or saved filters.** Those are admin pages ([`configuration.md`](configuration.md)).
- **No override points for the controllers.** The `modules/` tree is read-only at runtime; wrap a controller in your own partial instead of editing it.
